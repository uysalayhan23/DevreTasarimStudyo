# Arduino resmi örnek kaynakları ve lisans notları

Devre Tasarım Stüdyosu v1.19 içindeki Arduino IDE, resmi örnek kaynaklarını çevrimdışı gösterebilmek için aşağıdaki Arduino depolarındaki `.ino` dosyalarını içerir. Kaynak kod metni olduğu gibi saklanır; uygulamaya özel bilgiler ayrı metadata alanlarındadır.

| Kaynak | Kullanılan örnekler | Lisans notu |
| --- | --- | --- |
| arduino/arduino-examples | Built-in Examples | CC0 1.0 |
| arduino/ArduinoCore-avr | EEPROM, SPI, SoftwareSerial, Wire | Her dosyanın/orijinal kütüphanenin lisans bildirimi geçerlidir; kaynak yorumları korunur |
| arduino-libraries/Servo | Servo examples | GNU LGPL 2.1 |
| arduino-libraries/LiquidCrystal | LiquidCrystal examples | GNU LGPL 2.1 |
| arduino-libraries/Stepper | Stepper examples | GNU LGPL 2.1 |
| arduino-libraries/SD | SD examples | GNU GPL 3.0 depo lisansı; dosya başlıkları korunur |

Uygulama çalışma zamanında bu kaynaklara internet bağlantısı gerektirmez. IDE her resmi örnekte kaynak depo ve dosya yolunu gösterir.

Bu dosya hukuki tavsiye değildir; amacı üçüncü taraf kaynakların projede nereden geldiğini izlenebilir tutmaktır.
