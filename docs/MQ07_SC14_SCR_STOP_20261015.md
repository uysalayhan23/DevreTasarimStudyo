## Prior inconsistency and repair
- The SC14 demo used two distinct momentary inputs, SG (normally open gate pulse) and SP (normally closed anode STOP), but original simulation was a stateless gate-threshold switch. Releasing SG therefore switched the SCR off, teaching a physically wrong distinction.
- Reused SC13's narrowly opt-in `mq07ScrHoldLesson` SCR solver model in SC14's Q1, with the existing manufacturer catalog product `tyn612rg-scr`, virtual 12 V DC source, gate limiting resistor RG, SP series power path and 120 ohm instructional load H1. Preserved all seven original connection endpoints and existing layout.
- Updated SC14 summary, lesson explanation, learning goal and review status. The lesson now explicitly distinguishes **releasing SG** (SCR holds while the load current exceeds the virtual holding threshold) from **pressing SP** (anode current interrupted, latch drops). When SP is released without a new SG pulse, the circuit remains OFF.
- If SG is held during STOP restoration, another triggering command can immediately re-enable the load; the lesson explains this difference. The canonical tutorial source still labels the device as a non-calibrated virtual educational behavior with a real catalog identity, not physical hardware acceptance.
