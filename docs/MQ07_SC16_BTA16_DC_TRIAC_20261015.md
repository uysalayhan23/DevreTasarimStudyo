## MQ-05 virtual DC solver
- The generic TRIAC solver does not reproduce this entire instructional latch reliably with the full scene. A dedicated `solveSc16DcCycle` therefore checks actual pin-to-pin electrical connectivity (including junctions) and parameter limits, then applies an explicit current-holding state **only to SC16**. It is integrated into `dist/app.js` live simulation.
- Gate pulse requires valid SG and RG terminal paths; its virtual G–MT1 command reflects the 12 V DC source. If the load current meets the virtual threshold, Q1 latches. Releasing SG leaves Q1 ON. SP opens the main current path, clears the latch, and releasing SP alone does not restart the load. Holding SG while restoring SP constitutes a new trigger.
- Disconnecting a gate wire **before** triggering keeps the device OFF. Disconnecting a gate wire **after latching** does not by itself extinguish current. Removing MT1, MT2, power supply or series load continuity clears the latch; reconnection without gate pulse does not restart it.
- Fail-closed input checks: source 1–24 V numeric, minimum resistance and gate resistance, a bounded virtual holding threshold, correct product/type identity, non-short-circuited nets. State cleared on STOP/reset. This opt-in branch does not claim generic TRIAC models elsewhere are calibrated.
